Marketing Funnel & Conversion Performance Dashboard
Project Overview
This project uses Python and Streamlit to explore marketing funnel performance. It helps show how visitors move through the funnel, where potential customers drop off, and how different marketing channels perform.

This project was completed as part of the Future Interns – Data Science & Analytics Internship, Task 3.
Objectives
- Understand the stages of a marketing funnel.
- Track visitors, leads, qualified leads, and customers.
- Calculate conversion rates and drop-off between stages.
- Compare performance across marketing channels.
- View monthly marketing performance.
Dashboard Features
- Key performance indicator (KPI) cards
- Marketing funnel visualization
- Funnel conversion and drop-off analysis
- Channel-wise performance comparison
- Monthly performance trend
- Optional CSV upload, if enabled in the app
Tools Used
- Python
- Streamlit
- Pandas
- NumPy
- Plotly
Data
The dashboard creates demonstration data directly in the Python code. Therefore, a separate sample CSV file is not required to run the application.

The generated data is simulated for learning and demonstration purposes. It should not be treated as real company or customer data.

If the CSV upload option is used, the uploaded file should contain the columns expected by the application.
How to Run the Project
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal in the project folder.
4. Install the required libraries:
   pip install -r requirements.txt
5. Start the Streamlit application:
   streamlit run app.py
6. The dashboard will open in your browser.
Project Files
- app.py – Main Python application and dashboard
- requirements.txt – Required Python libraries
- README.md – Project documentation
Outcome
This project provides a simple interactive dashboard to understand marketing funnel conversion, identify drop-off stages, and compare marketing channel performance.
